Para comenzar a trabajar en el codigo del robot, deberan instalar los siguientes softwares para poder trabajar correctamente: VScode con extension a WPIlib (version vigente), FRC tools (version vigente), REV Client Hardware y Phoenix Tuner X. Los ultimos dos es software usado para configurar los controladores de nuestros motores, controladores VictorSPX y CANsparkMax respectivamente, estos dos programas pueden cambiar dependiendo de los controladores que se planeen usar, deberan buscar el software que configure el hardware de la respectiva empresa productora de los controladores.
VScode con extension wpilib (2024): https://docs.wpilib.org/es/stable/docs/zero-to-robot/step-2/wpilib-setup.html
FRC tools (2024): https://www.ni.com/es/support/downloads/drivers/download.frc-game-tools.html#500107
REV Hardware Client: https://docs.revrobotics.com/rev-hardware-client/
Phoenix Tuner X: https://apps.microsoft.com/detail/9NVV4PWDW27Z?hl=es-MX&gl=US
